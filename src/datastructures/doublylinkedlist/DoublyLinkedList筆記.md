# Doubly Linked List (雙向鏈結串列) 筆記

## 基本概念
- 每個節點 (Node) 除了資料 (value) 與指向下一個節點的指標 (next) 外，還多了一個指向前一個節點的指標 (prev)
- 維護 head (頭節點) 與 tail (尾節點) 以及 length (長度) 方便進行各項操作
- 因為擁有 prev 指標，所以允許雙向遍歷，尋找節點時更有效率
- 相比單向鏈結串列，每個節點需要額外的記憶體空間來儲存 prev 指標

## 常見操作與時間複雜度
- **新增節點**
  - 頭部新增 (prepend): O(1)
  - 尾部新增 (append): O(1)
  - 特定位置新增 (insert): O(n)
- **刪除節點**
  - 頭部刪除 (removeFirst): O(1)
  - 尾部刪除 (removeLast): O(1)，這是雙向鏈結串列的一大優勢，可以直接透過 tail.prev 找到前一個節點而無需從頭遍歷
  - 特定位置刪除 (remove): O(n)
- **修改節點**
  - 修改特定位置 (set): O(n)
- **查詢節點**
  - 查詢特定位置 (get): O(n)，實務上可透過判斷 index 在前半段還是後半段，決定從 head 往後找或從 tail 往前找，將遍歷次數減半以提升效率

## 實作細節與邊界條件
- 所有的增刪操作，都必須同時處理 next 與 prev 兩個指標的指向
- 插入與刪除節點時，需特別留意串列為空 (`length == 0`) 以及只有一個節點的極端情況
- 移除特定節點時，解開與前後節點的連結後，需要將被移除節點的 next 與 prev 都設為 null，以避免記憶體殘留並幫助垃圾回收 (Garbage Collection)
- 將串列清空時，記得將 `head` 與 `tail` 同時設為 null
