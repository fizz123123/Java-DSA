# Queue (佇列) 筆記

## 基本概念
- 是一種 FIFO (先進先出，First In First Out) 的資料結構，運作方式類似現實生活中的排隊隊伍
- 在底層實作上，通常維護 first (頭節點) 與 last (尾節點) 兩個指標來有效追蹤端點
- 單向操作特性：永遠從後端 (last) 加入新元素，從前端 (first) 移除舊元素

## 常見操作與時間複雜度
- **新增 (enqueue): O(1)**
  - 直接將新節點串連到目前的 last 節點之後
  - 更新 last 指標使其指向剛加入的新節點
  - 由於不需要從頭尋找尾部位置，因此時間複雜度為常數時間
- **刪除 (dequeue): O(1)**
  - 取出目前的 first 節點
  - 將 first 指標向後移動，指向下一個節點
  - 直接針對頭節點操作，不需走訪結構

## 實作細節與邊界條件
- 新增節點 (enqueue) 時，必須先判斷佇列是否為空 (`length == 0`)，若為空則需要將 first 與 last 同時指向新節點
- 移除節點 (dequeue) 時，需加入佇列為空的防呆機制 (直接回傳 null)
- 當透過 dequeue 移除佇列中「唯一」一個節點時 (`length == 1`)，務必將 first 與 last 同時設為 null
- 將節點從前端移除後，建議將該節點的 next 指標解除 (設為 null)，以利後續的垃圾回收 (Garbage Collection) 機制正確釋放記憶體
