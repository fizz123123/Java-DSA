# Linked List (鏈結串列) 筆記

## 基本概念
- 每個節點 (Node) 包含資料 (value) 以及指向下一個節點的指標 (next)
- 記憶體位址不連續，比起陣列更能彈性利用記憶體空間
- 在單向鏈結串列中，通常會維護 head (頭節點) 與 tail (尾節點) 以及 length (長度) 以利操作
- 查詢特定索引的時間複雜度為 O(n)，因為必須從頭從頭遍歷

## 常見操作與時間複雜度
- **新增節點**
  - 頭部新增 (prepend): O(1)
  - 尾部新增 (append): O(1)，前提是有維護 tail 指標
  - 特定位置新增 (insert): O(n)，需要先找到目標位置的前一個節點
- **刪除節點**
  - 頭部刪除 (removeFirst): O(1)
  - 尾部刪除 (removeLast): O(n)，單向無法直接往回找，必須從頭遍歷到 tail 的前一個節點
  - 特定位置刪除 (remove): O(n)
- **修改節點**
  - 修改特定位置 (set): O(n)，需要遍歷尋找目標節點
- **查詢節點**
  - 查詢特定位置 (get): O(n)

## 實作細節與邊界條件
- 插入與刪除時，需注意串列為空 (`length == 0`) 或是只有一個節點的特殊情況
- 刪除節點後，常需要將該節點的 next 指針設為 null 以幫助垃圾回收 (Garbage Collection)
- 當串列清空時，記得將 `head` 與 `tail` 同時設為 null
- 反轉串列 (reverse) 是經典操作，通常需要三個暫存變數 (temp, before, after) 來依序改變每個節點的 next 指向
