# Stack (堆疊) 筆記

## 基本概念
- 是一種 FILO (先進後出，First In Last Out) 的資料結構，運作方式類似彈夾或網球罐
- 所有的資料進出都只能從單一端點進行操作，這個端點通常被稱為頂部 (top)
- 在底層的自行實作上，通常會維護一個 top 指標與 height (高度/長度) 來有效追蹤目前狀態

## 常見操作與時間複雜度
- **新增 (push): O(1)**
  - 將新節點加入到堆疊的頂部
  - 把新節點的 next 指標指向目前的 top 節點，接著將 top 更新為該新節點
  - 由於只需要改變指標的對應關係，不需要走訪，因此時間複雜度為常數時間
- **刪除 (pop): O(1)**
  - 取出並移除目前的 top 節點
  - 將 top 指標向下移動到次一個節點 (`top = top.next`)
  - 同樣只需對頂部節點做指標操作即可完成

## 實作細節與邊界條件
- 執行 push 時，若遇到堆疊為空的問題 (`height == 0`)，可直接將 top 指向新創建的節點
- 執行 pop 時，必須加入堆疊為空的防呆判斷 (如直接回傳 null)，以免造成後續指標操作的錯誤
- 當透過 pop 將節點移除後，務必將該暫存節點的 next 指標設為 null，解除與原堆疊鏈結的耦合，藉此利於資源釋放與垃圾回收 (Garbage Collection) 機制的運作
