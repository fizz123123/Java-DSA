# 二元搜尋樹 (Binary Search Tree)

## 核心定義與特性
* 是一種非線性的階層式資料結構，由節點 (Node) 組成
* 每個節點最多只能有兩個子節點，分別稱為左子節點 (Left Child) 與右子節點 (Right Child)
* 任何節點的左子樹中，所有節點的值必定「小於」該節點的值
* 任何節點的右子樹中，所有節點的值必定「大於」該節點的值
* 根據標準定義，二元搜尋樹中不允許存在重複的值

## 效能與時間複雜度
* 最佳與平均情況下，搜尋、插入與刪除的時間複雜度皆為 O(log n)
* 在最壞情況下（例如依序插入已排序的資料，導致樹退化成單向鏈結串列），各種操作的時間複雜度會退化為 O(n)
* 空間複雜度則取決於樹的高度，代表遞迴的呼叫堆疊深度
* 最佳空間複雜度為 O(log n) (完美平衡時)
* 最差空間複雜度為 O(n) (極度不平衡時)
* 維持樹的平衡狀態對於確保 O(log n) 的高效能至關重要

## 樹的走訪方式 (Tree Traversal)

### BFS 廣度優先搜尋 (Breadth-First Search)
* 又稱為層序遍歷 (Level-Order Traversal)
* 走訪邏輯為一層一層由頂端往下，同一層由左至右橫向推進
* 實作上通常搭配佇列 (Queue) 來達成先進先出 (FIFO) 的迭代行為

### DFS 深度優先搜尋 (Depth-First Search)
* 走訪邏輯為沿著樹的某個分支盡可能往下鑽，直到碰壁 (Null) 才向上回溯
* 實作上通常依賴記憶體底層的呼叫堆疊 (Call Stack) 使用遞迴來達成
* 前序走訪 (PreOrder)
  * 走訪順序為：中 -> 左 -> 右
  * 應用場景：常用於序列化一棵樹，或是複製一棵樹的結構
* 中序走訪 (InOrder)
  * 走訪順序為：左 -> 中 -> 右
  * 核心觀念：對 BST 執行中序走訪，必定會得到一個呈現極大化遞增排序的序列
* 後序走訪 (PostOrder)
  * 走訪順序為：左 -> 右 -> 中
  * 應用場景：常用於由下而上執行運作，例如刪除整棵樹（需先刪除小孩才能刪除父母）

## 面試實戰重點與技巧
* 驗證合法性：判斷是否為合法的 BST，最優解是透過傳遞上下界 (Min/Max Boundary) 以 Top-Down 方式檢查
* 第 K 小元素：在找尋第 K 小節點時，可透過迭代式的中序走訪並搭配計數器，找到目標後提早結束以節省效能
* 空間優化：在處理樹狀結構演算法時，能利用遞迴傳遞狀態 (如邊界值、前一節點) 就盡量避免產生新陣列，以降低空間複雜度
